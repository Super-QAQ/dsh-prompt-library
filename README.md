# 提示词库 · Prompt library

把常用提示词保存一次，之后在任何会话里复用。

- 输入框左侧「提示词」面板：搜索、标签筛选、插入草稿、复制、新建/编辑/删除
- 从链接智能录入：抓页面后用默认模型提取现成提示词
- 依赖检查：`skill:` / `plugin:` 没装好时卡片标红，一键让 Agent 安装
- Agent 工具：`prompt_save`、`prompt_list`、`prompt_get`、`prompt_delete`、`prompt_import_url`

## 安装

```sh
dsh plugin --profile <profile> add dsh-prompt-library
```

也可以在 DSH 插件页用 **添加插件** 选择本目录。安装后新开一个会话生效；要求 DSH `>=0.2.2-rc.1 <0.3.0-0`（见 `engines.dsh`）。

## 在哪里用

- **输入框左侧的「提示词」按钮**：唯一的入口。打开提示词库，选中一条后点「插入」写进当前草稿，或点「复制」；没有会话时不显示。

面板贴在输入框正上方，宽度比输入框略窄（左右各留 12px），高度最多占屏幕的一半；点面板外任意处或按 Esc 关闭。面板里顶部是搜索框（匹配标题、正文和标签），下面是一排常用标签：点一下只显示带该标签的条目，再点或点「全部」取消。搜索行右侧的「新建」开始一条新提示词；新建/编辑时标签栏也能直接点选已有标签，不用手打。删除需要点两次：先「删除」，再「确认删除」。

## 从链接智能录入

新建/编辑表单顶部有「从链接智能录入」：

1. 粘贴一个网址（`http://` 或 `https://`），点「提取提示词」。
2. 插件抓取页面正文，交给**默认模型**：页面上有现成提示词（启动提示词、配方、模板、system 指令）就尽量原样提取；没有就总结一条可复用的。
3. 只找到 1 条会直接填进表单；多条会列出候选，点「采用」选一条，然后自己检查、保存。
4. 超过 90 秒会放弃；页面正文最多取 4 万字符，超出会标注截断。

新建表单默认只显示智能录入，「手动设置」是折叠的：点开才出现标题、标签、来源、正文。选完候选、或点保存时正文为空，都会自动展开并填入/提示；编辑已有条目时默认展开。

**注意**：这一步会产生一次网页请求 + 一次模型调用，页面正文会发送给模型供应商。不点这个按钮就不会有任何外部请求。需要先在设置里选好默认模型。

## 依赖（技能 / 插件）

有些提示词要先装好对应的技能或插件才有意义，所以在条目上可以记依赖：

- 写法：`skill:名称`、`plugin:包名`，纯文本（如 `codex`）会当作备注保留。
- 面板会**按当前会话**判断是否装好：技能走会话的技能目录（所以装在 `.agents/skills` 里的项目级技能也能识别），插件比对已安装的 bundle 与插件行。
- 卡片上直接标出来：可以用的显示「技能 archify」，没装的显示红色「插件 xxx · 未安装」，鼠标悬停提示先安装。
- 新建/编辑的「手动设置」里有「依赖（技能 / 插件）」一栏，下面会列出**已安装**的技能与插件，点一下即加入/移除，也可以手输。
- Agent 保存时同样可以带依赖：`prompt_save { requires: ["skill:archify"] }`；`prompt_get` 会返回每条依赖的就绪状态。
- 依赖只是提示，不会拦住插入或复制。
- 没装好时，卡片上那条红色的「未安装」本身就是个按钮：点一下会在这个会话里给 Agent 发一条安装任务，装完点「刷新」即可看到状态变正常。

## 让 Agent 一起用

保存和读取的是同一份数据，Agent 通过五个工具操作它：

| 工具 | 作用 |
| --- | --- |
| `prompt_save` | 保存一条提示词；带 `id` 时更新已有条目 |
| `prompt_list` | 列出摘要（标题、标签、字数、预览），可搜索 |
| `prompt_get` | 按 `id` 或完整标题读取正文 |
| `prompt_delete` | 按 `id` 删除一条 |
| `prompt_import_url` | 读一个链接并提取其中的提示词；`save: true` 时直接入库 |

例如让它「把刚才这段提示词存进提示词库」，之后在面板里就能看到。

## 数据在哪里

条目保存在本机：

```
~/.dsh/prompt-library/prompts.json
```

- 首次读取时如果文件不存在，会写入两条来自 [Archify 快速上手](https://archify.si/zh/start?type=architecture&agent=codex&source=direct&input=description) 的示例提示词。
- 文件就是普通 JSON，可以直接编辑或备份；面板、工具和文件始终读写同一份内容。
- 浏览器面板通过 Harness 认证的 `/api/prompt-library/prompts` 路由读写，只有本机的所有者能访问；提示词不会发送到任何外部服务。
- 停用或卸载插件不会删除该文件。

## 兼容性

- 需要 Web GUI（面板挂在 `conversation.input.left`、`sidebar.footer.action` 和 `shell.overlay` 三个插槽上）；纯终端环境只保留五个 Agent 工具。
- 样式只使用主题变量（`--dsw-alias-*` 与 `--dsw-focus-ring-*`），跟随明暗主题切换。
- 面板里点右上角刷新按钮可重新读取文件；Agent 用 `prompt_save` 写入后，已打开的面板需要刷新才显示新条目。
- 文章编辑未保存时按 Esc 或关闭会直接丢弃改动，长提示词请先「保存」。
